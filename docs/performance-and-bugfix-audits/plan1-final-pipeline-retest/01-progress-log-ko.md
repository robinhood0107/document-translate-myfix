- 남겨 둔 점:
  - 번역 길이 상한(원문 길이 ×6, 최소 64자)은 경험치라서 gate에서 오거부가 나오는지 확인한다.
  - 검증을 통과한 대상은 뒤의 대상이 실패해도 cache에 남는다. 게시가 아니므로 허용한다.

  - 더 큰 속도 개선 후보는 두 가지로, N7에서 다룬다. Gemma cache identity를 복구하는 것, 연속 실행에서 적재를 재사용하는 것.
  - F1 조건부 역할: 새 파이프라인 실행에는 기존 사용자 결정이 없어서 절감 효과가 0이다. 그래서 gate는 항상 호출과 OFF만 비교한다. 조건부 구현은 효과를 보여 줄 표본이 생길 때로 미룬다.

- 현재 확인한 정적 분류에서 P00 HTTP 1,162건 중 모델 목록 조회는 956건이다. OCR 추론 60, 번역 추론 34, 역할 추론 10건과 구분한다.
- 동일 원본의 39블록에서 P00/P01의 삭제·번역 대상은 32개, P10은 14개다. 나머지 검토/보존 판정이 실제 원본과 맞는지를 확인해야 한다. 수가 다르다는 이유만으로 탈락시키거나, 줄어든 시간을 품질 개선으로 인정하지 않는다.
- 같은 영어 표본의 두 구성에서 마스크 생성 121.284/122.529초, 모델 forward 3.106/2.548초가 관측됐다. 마스크 구간을 먼저 조사하되 개별 함수가 근본 원인이라고 확정하지 않는다.
- 앱의 성공 경로 best-effort 보고와 CI/실험 보고 계약 사이의 공백을 확인했다. 실패·취소·중단·측정 불가·보고 실패를 숨기지 않는 자동 기록 및 검사를 별도 작업으로 진행한다.
- 이번 단계에서 새 모델 실험과 최종 512회 실행은 하지 않았다. 기존 raw·완료 receipt는 수정하지 않았다.
