# 인페인트 품질 판정과 안전한 원본 보존

이 문서는 최종 파이프라인에서 **어떤 글자 영역을 자동으로 지우고 복원해도 되는지**를 정리한다. 기준은 제거 속도가 아니라 원본 그림의 보존이다. 불확실한 영역을 잘못 지워 그림을 손상시키는 것보다, 원본을 남기고 검토 대상으로 표시하는 편이 제품 품질에 맞다.

## 최종 정책

| 영역 유형 | 현재 처리 | 이유 |
|---|---|---|
| 일반 불투명 말풍선의 검증된 대사 | 기존 안전 경로로 번역·인페인트 | mask와 배경 복원의 품질 계약이 확인됨 |
| 반투명 말풍선 | 안전한 OCR·mask·복원이 모두 확인될 때만 자동 처리 | 글자 뒤 UI, 선화, 망점, 질감이 함께 지워질 수 있음 |
| 그림 위 의미 있는 자유 텍스트 | 안전한 복원이 확인될 때만 자동 처리 | 인물 윤곽·머리카락·배경 질감에 손상을 만들 수 있음 |
| 작은 UI, 장식 문자, 불확실한 SFX | 원본 보존 후 `review` 진단 | 잘못 번역하거나 지우는 손해가 이득보다 큼 |

`review`는 오류를 숨기는 상태가 아니다. 자동 파괴 편집을 하지 않았다는 이유와 원본 OCR·geometry 진단을 남겨 사용자가 후속 판단을 할 수 있게 하는 상태다.

## 왜 단순한 mask 밖 변경 0만으로는 부족한가

기존 품질 계약의 `mask` 밖 변경 픽셀 0은 필요한 안전장치지만 충분하지 않다. 말풍선 안쪽 mask에 다음처럼 **글자가 아닌 원본 그림**이 포함되면, mask 밖이 보존되어도 품질은 나빠진다.

- 반투명 패널 아래의 UI 선과 화면 질감
- 망점, 배경 선화, 규칙적인 반복 무늬
- 피부·머리카락·옷의 윤곽
- 말풍선 테두리와 그 뒤의 구조선

따라서 최종 품질 검수는 아래 순서로 한다.

1. 원문 잔상이나 읽을 수 있는 글자 조각이 남지 않는지 확인한다.
2. 말풍선 테두리, 선화, 망점, UI 직선, 인물 윤곽이 자연스럽게 이어지는지 확인한다.
3. 색이 평평하게 뭉치거나 흰 조각·회색 구멍·새 선형 무늬가 생기지 않는지 확인한다.
4. 번역문이 한 번만 렌더되고 원문과 겹치지 않는지 확인한다.
5. 위 조건을 모두 만족한 후보끼리만 속도와 VRAM을 비교한다.

## 시험한 접근과 판정

| 접근 | 확인한 장점 | 미채택 이유 |
|---|---|---|
| CTD refined mask + protect mask | 불필요한 넓은 삭제 범위를 줄임 | 반투명 구조 배경에서는 글자 획과 원본 선을 완전히 분리하지 못함 |
| LaMa Large FP32 | 고해상도 후보를 비교할 기준 제공 | 잔상 제거와 구조 보존을 동시에 만족하지 못함 |
| LaMa MPE FP32 | mask-aware 위치 정보를 활용 | UI·망점·선화가 겹친 경우의 공통 실패를 해소하지 못함 |
| AOT FP32 | 후보 중 빠른 복원 경로 | 질감과 반복 무늬 왜곡이 더 커질 수 있음 |
| ZITS 계열 FP32 feasibility | 선·구조 복원 가능성을 확인 | 자동 만화 복원 품질 게이트를 통과하지 못함 |
| 결정론적 국소 보정·선 연결 | 학습형 복원을 줄이는 보조 후보 | 원문 잔상, 평탄 패치 또는 가짜 선이 남아 미채택 |

이 결과는 모델 구현이 실패했다는 뜻이 아니라, **현재 입력만으로 가려진 원본 질감을 신뢰성 있게 되살릴 수 있는 자동 경로는 아직 없다는 뜻**이다. 따라서 FP32 후보는 진단·재현용으로 보존하지만 제품 기본값으로 바꾸지 않는다.

## 유지하는 공통 기반

이번 판정으로 다음 기반 기능을 제거하지 않는다.

- OCR 결과의 역할 분류와 `translate_inpaint` / `preserve` / `review` 동작 분리
- exact duplicate의 canonicalization으로 OCR·번역·인페인트·렌더 중복 방지
- CTD GPU mask refiner와 protect mask
- mask 밖 원본을 lossless로 합성하는 안전장치
- GPU 인페인터의 실제 device·precision·mask bbox·잔상 진단 기록
- OCR·mask·인페인트 정책이 바뀌면 cache identity와 project checkpoint schema를 갱신하는 계약

이 기반은 일반 말풍선에서는 계속 유효하며, 향후 새로운 복원 기술을 시험할 때도 동일한 품질 게이트를 적용할 수 있게 한다.

## 운영 불변 조건

- 학습형 인페인트는 CUDA에서만 실행한다. CPU fallback은 성공으로 처리하지 않는다.
- 한 번에 Paddle 또는 Manga OCR, inpainter, Gemma를 함께 GPU에 상주시키지 않는다.
- GPU OOM은 좁은 ROI 재시도까지 허용하되, CPU로 자동 후퇴하지 않는다.
- 불확실한 merge/split, 의미 역할, mask coverage는 자동 편집하지 않는다.
- 자동 재시도는 원본 mask 주변의 제한된 범위에서만 수행하며, 같은 실패를 무한 반복하지 않는다.
- 새 후보는 기존 안전 경로보다 깨끗하지 않으면 속도와 무관하게 미채택한다.
